AutoGrid360 Backup / Restore

A full AutoGrid360 inventory backup contains seller presentation profiles, complete listing/vehicle inventory, lifecycle state and history, stable portable listing identities, and listing images. Host-account passwords, sessions, MFA material, roles, account email, and other host identity data are not included.

Full Backup

Export every AutoGrid360 seller profile and listing across the installation. Seller ownership is represented by username so the backup can be restored to matching host users or explicitly remapped onto renamed destination accounts.

Download Full Inventory Backup

Restore Backup

Normal restore preserves Draft, Pending Review, Active, Sale Pending, Sold, Expired, and Removed states together with publication/expiration/sold history, featured state, view count, portable IDs, and images. Destination database IDs and reference IDs are rebuilt locally.

Source usernames map to destination host users with the same username automatically. For renamed accounts, enter one source=destination mapping per line. Every source seller must map to an existing, distinct destination user. AutoGrid360 never creates or restores host accounts.
