# Demo Assets

These images are synthetic sample vehicle photos used by `scripts/demo_listing_generator.py` when generating deterministic AutoGrid360 demo and QA inventory archives.

They are intentionally small, repository-friendly source assets rather than production listing media. AutoGrid360 still processes them through the normal listing-image validation, normalization, and storage pipeline during demo archive restore.

The images are provided only for project demonstration, testing, and development use.
